# Coding Standards

## General

- TypeScript only
- ES Modules
- Named exports
- Strict mode enabled

## Naming

Classes:
PascalCase

Interfaces:
PascalCase

Functions:
camelCase

Files:
PascalCase for React components
camelCase for utilities

## Formatting

- Prettier
- ESLint

## Imports

Always import through the package public API whenever possible.
